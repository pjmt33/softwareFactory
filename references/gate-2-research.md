# Gate 2: Research — Current State Only

You are documenting the codebase **as it exists today**. Do NOT propose designs,
recommend changes, or describe what should be built. Research precedes design;
its output is facts, not opinions.

## Questions (answer all four before writing)

1. Which files handle the area this feature touches? Group them by purpose:
   implementation, tests, config, types.
2. What existing patterns exist for this type of change? Include `file:line`
   references.
3. What tests already cover this area? What do they assert?
4. What are the integration points and external dependencies (names only)?

## Output format: `02-research.md`

- Files (grouped by purpose, paths only)
- Patterns (with file:line references)
- Test coverage (what exists, what's asserted)
- Dependencies (names only)
- Open questions (things you could not determine from code alone)

Do NOT include: design proposals, recommended approaches, or "we should".
