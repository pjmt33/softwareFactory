# Gate 3: Design Discussion — Desired State

Read `02-research.md`. Do NOT read `01-questions.md` or any product document.
Design decisions must be grounded in the current state described by research.

## Questions

1. What is the current state, and what is the desired end state?
2. What 2–3 key design choices exist? For each: options, recommendation,
   and why.
3. Which research findings constrain the design? (cite file:line)
4. What remains unresolved?

## Output format: `03-design-discussion.md`

- Current state (from research, with references)
- Desired end state
- Design choices (2–3, each with options and recommendation)
- Resolved decisions
- Open questions (must be empty or explicitly deferred before Gate 4)
