# Product: factory-webui

## Problem
Operators need a single page showing every plan's gate status and phase progress, so a fresh session doesn't have to read four 00-status.md files.

## Success metric
The page lists every plan with its next gate or "all gates approved" and its phase checkboxes; read-only, no execution.

## Announcement — the blog post before the feature
Open the factory page and see every plan, every gate, every phase — no terminal, no status files.
